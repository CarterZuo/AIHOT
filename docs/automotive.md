# 汽车产业情报：本地定制与启用边界

本次改动把示例站改为「汽车产业情报」。当前是本地开发配置，不代表生产上线、稳定采集或精选质量已经验收。站名已由使用者确认，以下覆盖方案按其五项关注范围制定。

## 分类和内容边界

| 页面分类 | 关注内容 | 必须保留的边界 |
|---|---|---|
| 国家政策 | 汽车产业、消费、准入、税费和监管 | 发布机关、正式/征求意见、适用条件、生效与截止时间 |
| 地方政策 | 补贴、置换、限购限行、地方实施细则 | 地区、资格、额度和申请期限，不扩展成全国 |
| 企业动态 | 中国市场中资、合资、外方独资车企的经营、渠道、组织和合作 | 所有制有证据才标，不按品牌国别推断 |
| 产品动态 | 新车、改款、价格权益、OTA | 车型/年款、上市/预售、指导价/成交价及权益条件 |
| 客户服务 | 质保、正式召回、服务网络、补能和客户权益 | 适用车辆、批次、时间与处理阶段 |
| 汽车出口 | 国内及目的国政策、关税认证、出口经营和渠道 | 国内公开来源报道的法域和阶段，不把提案当生效 |
| 长马口碑 | 本品媒体实测、车主评价、投诉和后续回应 | 观点、陈述、回复和监管认定分别归属来源；个案不是缺陷率 |
| 数字化与AI | 汽车数智应用、跨行业企业转型与To B应用、AI产业动态、经证据审查的社区观察 | 按四个互斥主题标签区分；方案/试点/上线/实测分清，收益保留基准、样本和人工复核条件 |

主题目录含车企/集团、业务方向、本品车型、企业AI案例地域和内容形态入口。集团、合资企业与品牌分开匹配。数字化与AI依2026-10-24用户批准的四层范围收录，不再要求每篇都有汽车关联；保留原行业与主体，不补造汽车应用。四层是内容标签与价值判断方向，不是四档强制排序，不改变精选数值门槛。EZ-6、EZ-60、CX-50、CX-5、CX-30、MAZDA 3 昂克赛拉列入关注范围；这不是当前在售状态认定，历史与海外车型需据原文核对。

### DNS和采集修复

- 根因：本机 iKuuuVPN 的 TUN 路径返回 `198.18.x.x` 假IP，系统解析和普通公共DNS请求均受影响；原采集器正确拦截。
- 修复作用域是**本站进程**，不是修改整机DNS或关闭VPN。`.env` 配置 `OUTBOUND_DNS_URL=https://223.5.5.5/resolve`，通过公网IP的HTTPS入口解析真实公网地址，保留TLS证书校验。
- DNS结果、每次重定向、实际建连地址均经过原有私网/保留地址检查。假IP、回环、云元数据、混合公网与私网回答、DNS重绑定仍被拒绝。未启用 `ALLOW_PRIVATE_NETWORK_FETCH`，未添加私网信源例外。服务失败时保留失败，不退回不安全抓取。
- 复用已有DNS JSON解析、5秒超时、64KiB响应上限和最多60秒TTL缓存。DNS入口必须为无账号凭证的公网IP HTTPS URL；未配置时保持原系统DNS行为。
- HTML列表请求不再声明接收JSON，修复车质网因请求头返回JSON字符串而被当成HTML的问题。
- 长马适配放在 `modules/automotive/`，通过通用模块插口接入列表和详情。合并普通及置顶列表并按原文URL去重；详情ID必须与页面ID一致，正文仍由通用提取器清洗。已观察到一篇响应10,744,123字节，故仅该接口设置16MiB上限，移除内嵌图片，不放宽全站响应限制。
- 短投诉使用现有 `detail.summarySelector` 保留文字，不降低全站200字正文判定标准。只取得标题或列表时不宣称取得正文。

可复现的只读验收（不入库、不调用付费渲染或模型、不推送）：

```bash
node --env-file=.env modules/automotive/scripts/check-sources.ts
```

证据保存在 `.data/source-validation/acceptance.json`（真实DNS、标题、URL、日期、正文或摘要长度）和 `admin-acceptance.json`（已运行后台的逐源试抓）；未提交到Git。该轮只读试抓的回执检查为0→0，文章为0。此后已执行一次性入库，最新状态见下节；8源仍暂停，全局采集关闭。后台“试抓”本身不会入库。

**覆盖缺口：** 江苏汽车以旧换新栏目含嵌入式列表；工信部列表与部分车企正文动态加载，尚未完成现有采集器适配。车质网公开车主口碑列表同时含优点与缺点，但没有可供当前通用列表采集器使用的逐条链接，因此目前没有把它伪装成稳定自动口碑源。可人工阅读 [EZ-60车主口碑](https://www.12365auto.com/review/4348_0_0_1.shtml)。投诉不能代表完整口碑，也不能代表全网舆情。
